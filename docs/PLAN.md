Ниже изначальные идеи и сообщения о сути проекта.

придумал бота, который много кому нужен: создатель инструкций из пересланных сообщений.

Этот бот - универсальный инструмент суммаризации пересланных Telegram сообщений, чтобы можно было сохранять прикреплённые медиа, главное чтобы можно было степень обработки менять (больше цитировать или больше пересказывать)

это должен быть телеграм бот, которому пересылаешь пачку сообщений, он их добавляет в контекст и пишет в Telegram ответ: что хотите с ними сделать? И кнопки формы: степень обработки: min, mid, max, формат: markdown, pdf, docx, сохранять медиа: да, нет

Юзер делает выбор, бот отправляет сообщение о статусе, что началась обработка. После этого редактировать сообщение о статусе, в итоге оно превратится с markdown текстом пересказа и/или прикреплёнными файлами. 
 
Для конвертации использовать готовые пакеты небольшого размера, не надо тащить libreoffice. Я точно знаю, что для генерации docx есть лёгкое что-то, для pdf тоже наверняка есть.

Модель будет gpt-5-nano наверное, минимальная, которая способна стабильно повторять текст.

Язык python, нужно использовать официальные openai agent sdk или другой agent sdk.

Боевой запуск будет в docker-compose.

Нужна статистика по пользователям, какой пользователь сколько входных и выходных токенов потратил. В целом за всё время и за сегодня, чтобы применять лимиты.

Пользоваться можно только юзерам, которые имеют username.

Нужно добавить лимиты по username. Default: 10000 токенов на вход, 10000 токенов на выход. Возможность указать другие defaults в конфиге. Возможность переопределить лимит для выбранных username.

Можно использовать для лимитов json или sqlite, юзеров будет немного.

Конфиг будет в yml.
